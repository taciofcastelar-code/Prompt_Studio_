PROMPT STUDIO V4.2 ULTIMATE — LOCAL-FIRST

Objetivo:
Levar o Prompt Studio ao máximo de funcionalidades possíveis sem depender de IA externa, servidor próprio ou assinatura paga.

Inclui:
- Painel completo
- Projetos
- Arquiteto de Prompts
- Detecção automática de intenção/modo
- Estratégias por tipo de tarefa
- Médico de Prompts
- Biblioteca
- Favoritos
- Tags
- Versionamento de prompts
- Modelos/templates
- Laboratório de testes
- Métricas reais: qualidade, precisão, utilidade
- Comparador A/B
- Fluxos e cadeias
- Análises
- Registro de problemas do app
- Backup/importação JSON
- Limpeza total de dados
- IndexedDB
- PWA compatível
- Interface em português

ARQUIVOS PARA SUBSTITUIR:
src/main.js
src/styles.css
src/modules/intelligence.js
src/modules/scoring.js
src/services/local-db.js

NÃO ALTERE:
.github/workflows/deploy.yml

IMPORTANTE:
Esta versão usa um novo banco local: prompt-studio-v4-2.
Os dados antigos da V4.1 não são migrados automaticamente.
